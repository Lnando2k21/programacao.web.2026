# Landing Page Interativa — Território de Passagem

Atividade individual Tema: **Território Quilombola de Passagem, Monte Alegre — Pará**.

## Arquivos
- `index.html` — estrutura HTML5.
- `estilo.css` — CSS externo.
- `script.js` — DOM e eventos JavaScript.

## Requisitos inseridos no projeto
- HTML completo, navegação, textos, botões, input, textarea e formulário.
- CSS externo, seletores por tag/classe/ID, layout responsivo e modo escuro.
- `getElementById()`, `.value`, `textContent`, `.style` e `classList`.
- Eventos `click`, `input` e `submit`.
- `event.preventDefault()`.
- Código separado, comentado e com nomes descritivos.
- Apenas HTML, CSS e JavaScript puro; sem framework, API, backend ou `fetch`.

## Base documental do conteúdo
- UFOPA, Edmar Monteiro de Jesus: *Quilombo de Passagem: conflitos, demarcação e titulação (2009 a 2019)*.
- Ministério Público Federal: Recomendação nº 1/2025 sobre a regularização do Quilombo Passagem.
- Instituto Socioambiental: *Protocolo de Consulta prévia, livre e informada dos quilombos Passagem, Nazaré do Airi e Peafú*, 2020.
